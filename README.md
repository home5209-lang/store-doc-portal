# 매장 발신번호 등록 서류 포털 (프로토타입)

매장이 링크 하나로 접속해서 서류 2개(통신서비스 이용증명원, 사업자 등록증)만 올리면,
나머지 3개(계약서, 사용승낙서, 재직증명서)는 자동으로 채워지는 흐름을 실제로 돌려볼 수 있는 프로토타입입니다.

## 지금 이게 실제로 하는 일

1. `/upload/:storeId` 접속 → 매장 정보 입력 + 서류 2개 업로드
2. 제출하면:
   - 업로드한 2개 서류를 서버에 저장
   - 계약서 자리에 안내용 예시 파일을 자동으로 채움 (모두싸인 연동 자리, 지금은 스텁)
   - 사용승낙서 / 재직증명서를 매장이 입력한 정보로 실제 `.docx` 파일로 자동 생성
3. `/admin` 접속 → 매장별로 5개 서류가 다 모였는지, 제출 상태가 어떤지 확인하고 각 파일을 다운로드

## 실행 방법 (내 컴퓨터에서 눈으로 확인하기)

터미널에서 이 폴더로 이동한 뒤, 관리자 로그인 계정을 환경변수로 정하고 실행합니다 (PowerShell 기준):

```powershell
npm install
$env:ADMIN_USER = "admin"
$env:ADMIN_PASS = "원하는 비밀번호"
npm start
```

`ADMIN_USER` / `ADMIN_PASS`를 설정하지 않으면 `/admin`은 503 에러만 내려주고 아예 열리지 않습니다.

그다음 브라우저에서:
- 관리자 페이지: `http://localhost:3000/admin` → 접속하면 브라우저가 로그인 창을 띄웁니다 (`ADMIN_USER`/`ADMIN_PASS`로 로그인). 로그인 후 상단에서 매장명을 입력하고 "업로드 링크 발급"을 누르면 만료 시각이 포함된 업로드 링크가 발급됩니다 (기본 7일 유효).
- 발급된 업로드 링크로 접속해서 서류를 제출해보면 `generated/<storeId>/` 폴더 안에 실제 `.docx` 파일이 생기는 걸 확인할 수 있어요.
- 터미널을 시작할 때도 콘솔에 샘플 업로드 링크가 하나 출력됩니다.

업로드 링크는 `/upload/:storeId/:token` 형태이며, `storeId`와 만료시각을 서버가 `LINK_SECRET`으로 서명해서 만듭니다. 만료되었거나 서명이 맞지 않으면 안내 화면만 뜨고 서류 제출은 불가능합니다.

## 이 프로토타입에서 "가짜"로 처리한 부분 (다음 단계에서 진짜로 바꿔야 할 것)

| 부분 | 지금 상태 | 진짜로 만들려면 |
|---|---|---|
| 계약서 자동 첨부 | `contractStub.js`가 안내 텍스트 파일을 대신 넣음 | 모두싸인 개발자센터에서 API 키 발급받고, 이 파일 안의 함수를 실제 API 호출로 교체 |
| 업로드 링크 보안 | ✅ 완료 — `tokens.js`가 매장 ID + 만료시각을 HMAC으로 서명한 토큰을 발급 (`/upload/:storeId/:token`, 기본 7일 만료). `/admin`에서 매장별로 링크 발급/재발급 가능 | 운영 배포 시 `LINK_SECRET` 환경변수를 반드시 설정 (미설정 시 개발용 기본값 사용, 콘솔에 경고 출력) |
| 파일/DB 저장 위치 | 로컬 폴더 + SQLite 파일 | 실제 서비스에서는 여러 서버 인스턴스에서도 안전하게 공유되는 저장소가 필요 (Supabase Storage + Postgres 같은 서비스 추천) |
| 관리자 페이지 | ✅ 완료 — `auth.js`가 HTTP Basic Auth로 `/admin` 이하 전체(현황판, 링크 발급, 서류 다운로드)를 막음. `ADMIN_USER`/`ADMIN_PASS` 환경변수로 로그인 | 운영 배포 시 계정을 더 안전하게 관리하려면 다중 관리자 계정, 비밀번호 해시 저장, 세션 로그인 UI 등으로 확장 |
| NHN 제출 | 없음 (사람이 서류 모아서 직접 제출한다고 가정) | NHN 쪽에 심사 요청 API가 있는지 확인 후 자동화 가능 여부 검토 |
| 사업자등록증 3개월 이내 조건 | 체크 안 함 | 발급일자 입력칸을 추가하고 서버에서 날짜 검증 로직 추가 |

## 폴더 구조

```
server.js         진입점, 라우팅
db.js             SQLite 스키마 + 조회/저장 함수
docGenerator.js   사용승낙서 / 재직증명서 자동 생성 로직
contractStub.js   계약서 자동 첨부 자리 (모두싸인 연동 지점)
tokens.js         업로드 링크용 만료 서명 토큰 생성/검증
auth.js           관리자 페이지 Basic Auth 미들웨어
views/            업로드 페이지 / 제출완료 페이지 / 관리자 페이지 HTML
uploads/          매장이 올린 원본 파일 저장 위치
generated/        자동 생성/첨부된 파일 저장 위치
db/               SQLite 데이터베이스 파일
```
